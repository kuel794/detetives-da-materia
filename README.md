# Detetives da Matéria

**Missão: investigar, identificar e separar!**

Site interativo da Feira de Química para tablet: os visitantes estudam matéria, energia, substâncias e misturas, resolvem cinco casos com uma lupa virtual, veem os métodos de separação animados, encaram um desafio com tempo e recebem um certificado com foto de detetive.

- **Instituição:** UNIMAM · Centro Universitário Maria Milza
- **Disciplina:** Química Geral e Inorgânica
- **Docente:** Uiara Souza
- **Discentes:** Amanda, Andressa, Bruna, Késsia, Larah e Sheila
- **Sistema desenvolvido por:** Quervin Damasceno do Nascimento · @quervin__

Feito em HTML, CSS e JavaScript, sem dependências externas. Depois de aberto uma vez, funciona sem internet. A foto do visitante não sai do aparelho.
